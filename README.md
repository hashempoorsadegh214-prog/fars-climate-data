# FARS Climate Data Downloader

این پروژه برای دانلود و استخراج داده‌های اقلیمی (CMIP6) مرکز اروپایی (Copernicus CDS / ECMWF) برای **استان فارس** طراحی شده است.

## ویژگی‌ها
- محدوده جغرافیایی اختصاصی استان فارس
- پشتیبانی از ۳ مدل اقلیمی برتر (EC-Earth3, MPI-ESM1-2-HR, NorESM2-MM)
- دانلود امن با متغیرهای محیطی بدون لو رفتن API Key

## پیش‌نیازها
- پایتون ۳.۸ یا بالاتر
- اکانت Copernicus CDS و API Key
